# GraphOWL examples

Runnable examples and synthetic sample data for [GraphOWL](https://github.com/graphowl/graphowl), the knowledge graph engine. Apache-2.0, early access.

| Example | What it shows |
|---|---|
| [`dairy-cooperative/`](dairy-cooperative) | A fictional dairy cooperative's database (SQL): the data behind the live demo. Load it, connect it, and let GraphOWL propose an ontology from it. |
| [`sparql-python/`](sparql-python) | Ask a SPARQL question over the HTTP API from Python with no dependencies, now or as of an earlier moment. |

For pushing data in, see the client libraries: [`sdk-python`](https://github.com/graphowl/sdk-python) (which includes a complete CSV adapter) and [`sdk-typescript`](https://github.com/graphowl/sdk-typescript).

The demo server needs a passcode: [get one](https://demo.graphowl.app/__access/book) by booking a 20-minute hands-on slot (or email <connect@graphowl.app>). Use it as the bearer token. Everything here uses synthetic data only.
